# 📌 Guide d’utilisation de l’IA

## Pour le cours **Vue.js – Concepteurs développeurs**

Dans ce module, nous apprenons à utiliser **Vue 3**, en particulier le **Composition API**, avec un environnement moderne basé sur **Vite**.  
L’objectif principal est que vous soyez capables de :

- créer des **composants Vue**,  
- comprendre la **réactivité**, les **composants**, les **principales directives du framework**,  
- gérer un **projet Vue**.

L’IA (ChatGPT, Copilot, etc.) peut vous aider, **mais uniquement pour accélérer certaines tâches**, pas pour remplacer votre logique ou votre compréhension du framework.

---

##  Ce que vous pouvez demander à l’IA

### ✔ Pour gagner du temps sur le visuel / structure

- Générer des **templates HTML** exploitables dans un composant Vue.  
- Produire des exemples de composants UI (cards, navbar, formulaires…).  
- Donner des snippets CSS, Tailwind ou Bootstrap.  
- Générer une mise en page responsive.  
- Expliquer des classes CSS ou des directives Vue.  
- Améliorer la lisibilité d’un composant sans changer sa logique.

### ✔ Pour mieux comprendre Vue

- Expliquer le fonctionnement d’une directive (`v-bind`, `v-on`, etc.).  
- Clarifier les notions de **syntaxe**, **directives**, **composants**.  
- Expliquer un code **que vous avez déjà écrit**.

---

## ❌ Ce que vous NE devez pas demander à l’IA

### ❌ Pas de délégation de logique Vue

- Ne demandez pas de créer vos **fonctions métier**.  
- Ne demandez pas de construire des composants Vue entiers avec toute la logique.  
- Ne demandez pas de générer la configuration complète du projet ou l’arborescence.

### ❌ Pas de code “copier-coller”

- Vous devez **comprendre chaque ligne** que vous utilisez.  
- Vous devez être capables d'expliquer votre code en cours et en projet.

### ❌ Pas d'automatisation du travail évalué

- L’IA n’écrit **pas vos exercices**, ni vos livrables.  
- Le but est d'apprendre, pas de contourner les difficultés.

---

##  Objectifs pédagogiques du cadre IA

- **Maîtriser Vue 3** et ses concepts fondamentaux.  
- Améliorer votre capacité à **comprendre et structurer** du code.  
- Développer un **esprit critique** vis-à-vis du code généré.  
- Utiliser l’IA comme **outil d’assistance**, pas comme substitut.

---

##  Prompts utiles pour Vue.js

### 1. Générer un template HTML stylé pour un composant Vue

Propose-moi un HTML propre et responsive pour un composant Vue 3 (Composition API),
qui affiche une card avec image, titre et bouton.
N’ajoute aucune logique JavaScript, uniquement le template.

### 2. Obtenir une explication sans recevoir de code

Explique-moi simplement comment fonctionne v-on sur un input dans Vue 3,
et comment on peut réagir à des evenenements.

### 3. Générer du CSS/Tailwind

Génère un style Tailwind pour une section responsive à trois colonnes
que je pourrais intégrer dans un composant Vue.

### 4. Demande de squelette de composant

Génère le squelette d’un composant Vue 3 avec `<script setup>`, `<template>`, `<style scoped>`
sans ajouter de logique métier.

---

##  Conclusion

L’IA est là pour vous **assister**, pas pour faire à votre place.  
Elle vous aide sur le **visuel**, sur la **compréhension**, mais jamais sur la **logique** ou la **réalisation complète** des exercices.

Bonne pratique et bon apprentissage avec Vue ! 🚀
