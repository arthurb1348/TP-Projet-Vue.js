# Vue.js — Cours et exercices

Projet d’apprentissage réalisé pendant ma formation de Concepteur développeur d’applications (CDA).

Il regroupe mes cours et exercices pour découvrir progressivement Vue.js et comprendre son fonctionnement.

## Technologies

- Vue 3 — Composition API avec `<script setup>`
- Vue Router
- Vite
- JavaScript, HTML et CSS

## Contenu

- Une page regroupant les cours.
- Une page donnant accès aux exercices.
- Une navigation entre les pages avec Vue Router.

### Exercices réalisés

1. **Interpolation de texte** : afficher des variables, des propriétés d’objets et des expressions JavaScript.
2. **Liaison d’attributs** : définir les attributs d’une image et de liens avec `v-bind` et son raccourci `:`.

## Lancer le projet

Prérequis : Node.js et npm installés.

Dans le dossier du projet :

```bash
npm install
npm run dev
```

Ouvrir ensuite l’adresse affichée dans le terminal.

## Organisation

- `src/components/` : composants partagés, notamment le header et le footer.
- `src/views/` : pages, cours et exercices.
- `src/router/` : configuration des routes.
- `src/assets/` : ressources du projet.
